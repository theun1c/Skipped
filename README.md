# Skipped - Трекер пропусков пар

Простое веб-приложение на Ruby с использованием Sinatra для отслеживания посещаемости занятий в колледже.

## Описание

- 🟢 **Зеленый** - присутствовал на всех парах
- 🟡 **Желтый** - пришел на 1-2 пары (частичное присутствие)
- 🔴 **Красный** - полностью пропустил день

### Установка

Клонируйте репозиторий:

```bash
git clone <repository-url>
cd Skipped
```

### Разработка с Docker

Для запуска приложения используйте Docker (присутствует в директории):

#### Сборка и запуск

```bash
# Сборка Docker образа
docker build -t skipped-app .

# Запуск контейнера
docker run -p 4567:4567 skipped-app
```

#### Для разработки с интерактивным доступом

```bash
# Запуск контейнера для разработки
docker run --rm -it -p 4567:4567 -v ${PWD}:/app -w /app skipped-app /bin/bash

# Внутри контейнера
bundle exec ruby app.rb -o 0.0.0.0
```

После запуска откройте браузер и перейдите по адресу: **http://localhost:4567**
